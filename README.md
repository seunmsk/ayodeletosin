# ayodeletosin.com

Personal website for Tosin Ayodele (CFM, FMP, PMP), facilities manager in Lagos.

Plain static site, no build step. Deployed on Cloudflare Pages: every push to `main` goes live.

- `index.html` – page content
- `styles.css` – styles
- `script.js` – data for the tabs, career timeline and cards, plus the interactions
- `assets/` – photo and favicon. Add `Tosin-Ayodele-CV.pdf` here to show the Download CV button.
